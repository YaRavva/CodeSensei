## Введение

Консоль — это окно, где программа пишет сообщения и читает ответы. Это как переписка в чате, только между программой и пользователем.

## Вывод текста в консоль

Когда вы хотите показать пользователю сообщение, используйте функцию **print**. Она принимает любой текст и выводит его на экран.

Пример:

```python
print('Привет, мир!')
```

Вы увидите:

```
Привет, мир!
```

### Простейший пример вывода

```python
print('Привет, мир!')
```

**Вывод:**
```
Привет, мир!

```

*Функция print выводит строку "Привет, мир!" в консоль.*

## Получение пользовательского ввода

Чтобы программа могла узнать, что хочет пользователь, используйте функцию **input**. Она показывает приглашение и ждёт, пока пользователь нажмёт Enter.

Пример:

```python
name = input('Как тебя зовут? ')
print(f'Привет, {name}!')
```

Если пользователь введёт "Аня", вы увидите:

```
Как тебя зовут? Аня
Привет, Аня!
```

### Запрос имени пользователя

```python
name = input('Как тебя зовут? ')
print(f'Привет, {name}!')
```

**Вывод:**
```
Как тебя зовут? Аня
Привет, Аня!

```

*input запоминает введённый текст в переменную name, а print выводит приветствие с этим именем.*

## Форматированный вывод

Иногда нужно вывести несколько переменных в одном сообщении. Для этого удобно использовать **f-строки** (f-strings). Они позволяют вставлять значения переменных прямо в текст.

Пример:

```python
age = 12
print(f'Мне {age} лет.')
```

Вы увидите:

```
Мне 12 лет.
```

### Вывод возраста с помощью f-строки

```python
age = 12
print(f'Мне {age} лет.')
```

**Вывод:**
```
Мне 12 лет.

```

*f-строка заменяет {age} на значение переменной age.*
