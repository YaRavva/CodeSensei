  ## Введение
  
  Консоль — это окно, где программа пишет сообщения и читает ответы. Это как переписка в чате, только между программой 
и пользователем.
  
  ## Вывод текста в консоль
  
  Когда вы хотите показать пользователю сообщение, используйте функцию **print**. Она принимает любой текст и выводит е
го на экран.
  
  Пример:
  
  ```python
  print('Привет, мир!')
  ```
  
  Вы увидите:
  
  ```
  Привет, мир!
  ```
  
  ### Простейший пример вывода
  
  ```python
  print('Привет, мир!')
  ```
  
  **Вывод:**
  ```
  Привет, мир!
  
  ```
  
  *Функция print выводит строку "Привет, мир!" в консоль.*
  
  ## Получение пользовательского ввода
  
  Чтобы программа могла узнать, что хочет пользователь, используйте функцию **input**. Она показывает приглашение и ждё
т, пока пользователь нажмёт Enter.
  
  Пример:
  
  ```python
  name = input('Как тебя зовут? ')
  print(f'Привет, {name}!')
  ```
