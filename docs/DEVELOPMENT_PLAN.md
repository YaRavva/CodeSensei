## 🎯 Обзор проекта

**Цель:** Создание интерактивного Python-тренажера с геймификацией для школьников 7-9 классов.

**Основные функции MVP:**
- Аутентификация и профили пользователей
- Просмотр модулей и заданий (урок = теория модуля + список задач)
- Редактор кода с выполнением через Pyodide
- Тестирование и AI-оценка решений
- Система прогресса и XP
- Таблица лидеров
- Админ-панель для управления модулями и заданиями

---

## 🛠 Технический стек

### Frontend
- **Next.js** (последняя версия, App Router)
- **TypeScript** (последняя версия)
- **React** (последняя версия)
- **shadcn/ui** (использовать MCP сервер shadcn для компонентов)
- **Tailwind CSS** (последняя версия)
- **Monaco Editor** (последняя версия)
- **Biome** (вместо ESLint, последняя версия)

### Backend
- **Vercel** (Serverless Functions)
- **Supabase** (использовать MCP сервер Supabase для миграций и запросов)
- **Supabase RLS** (безопасность)

### Выполнение кода
- **Pyodide** (последняя версия, WebAssembly)

### AI
- **Hugging Face Inference API**
- **openai/gpt-oss-20b** (ограничение 300 запросов/час)

### Важные инструменты
- **MCP Supabase** - использовать для всех операций с БД (миграции, запросы)
- **MCP shadcn** - использовать для добавления компонентов UI

## ⚠️ Риски и зависимости

### Технические риски
1. **Pyodide размер и загрузка**
   - Риск: Большой размер (~8-10 MB) может замедлить загрузку
   - Митигация: Lazy loading, прогресс-бар, кэширование

2. **Ограничения Pyodide**
   - Риск: Не все библиотеки Python поддерживаются
   - Митигация: Использовать только стандартную библиотеку, тестировать заранее

3. **Rate limits Hugging Face API**
   - Риск: Лимит 300 запросов/час
   - Митигация: Очереди, батчинг, кэширование по хэшу кода/версии задачи, деградация к локальным тестам

4. **Supabase limits**
   - Риск: Free tier имеет ограничения
   - Митигация: Оптимизация запросов, мониторинг использования

### Зависимости
- **Supabase проект** уже создан, ключи в .env
- **Hugging Face API ключ** должен быть в .env
- **Vercel аккаунт** для деплоя

### Блокеры
- Создание миграций БД блокирует разработку фронтенда
- Настройка RLS блокирует тестирование функций пользователей
- Pyodide интеграция блокирует тестирование решений
