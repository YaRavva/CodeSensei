# Цели проекта и общие требования (CodeSensei)

## 1. Цели проекта (Goals)

**CodeSensei** — это интерактивная веб-платформа для обучения программированию на Python, ориентированная на школьников 7–9 классов. Основные цели проекта:
- **Раннее погружение в реальный код**: Предоставление возможности писать настоящий Python-код с первых уроков без необходимости сложной локальной настройки окружения.
- **Мгновенная обратная связь**: Запуск и проверка кода прямо в браузере в режиме реального времени с помощью клиентской среды WebAssembly (Pyodide).
- **Игровые механики и геймификация**: Мотивация учащихся через систему опыта (XP), уровней, достижений (бэджей) и таблицы лидеров.
- **Хранение прогресса**: Сохранение индивидуального прогресса пользователей, истории решений и достижений с возможностью авторизации через email/пароль или OAuth (Google, GitHub).
- **Удобная панель администратора**: Инструменты для преподавателей и администраторов по созданию, редактированию и управлению учебными модулями и задачами.

## 2. Общие требования (General Requirements)

### Функциональные требования
- **Аутентификация и авторизация**: Поддержка регистрации, входа, восстановления пароля и входа через внешние OAuth-провайдеры (Google, GitHub) с безопасной сессионной авторизацией.
- **Учебный процесс**: Наличие структурированных модулей, разделенных на базовые и углубленные уровни, с теоретическими материалами в формате Markdown и практическими задачами.
- **Интерактивный редактор кода**: Встроенный редактор (на базе Monaco Editor) с подсветкой синтаксиса и возможностью запуска кода.
- **Автоматическое тестирование**: Набор тест-кейсов (видимых и скрытых) для каждой задачи, проверяющих корректность решения.
- **Интеграция с ИИ**: Генерация подсказок, помощи и оценивание решений через Omniroute AI.

### Нефункциональные требования
- **Производительность**: Быстрая загрузка страниц и мгновенный запуск тестов в браузере за счет Pyodide; оптимизированная серверная часть на Next.js App Router.
- **Надежность и масштабируемость**: Использование бессерверной/контейнерной архитектуры саморазвотываемого Appwrite (База данных TablesDB, Auth, Sites).
- **Адаптивность (Responsive Design)**: Корректное отображение интерфейса на любых устройствах, компактная верстка экранов авторизации без вертикального скролла.
- **Локализация**: Интерфейс полностью на русском языке, ориентированный на русскоязычную аудиторию школьников.
- **Документированность (Spec Graph)**: Все архитектурные решения и изменения фиксируются в графе спецификаций проекта.
