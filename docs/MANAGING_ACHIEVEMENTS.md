# Управление достижениями

Достижения хранятся в self-hosted Appwrite: база `codesensei`, таблица
`achievements`. Изменения в БД применяются сразу и не требуют передеплоя сайта —
передеплой нужен только при изменении кода отображения иконок.

## Где менять

### Через Appwrite Console

1. Откройте [Appwrite Console](https://appwrite.ravva.su) → проект **CodeSensei**.
2. Перейдите в **Databases → codesensei → achievements**.
3. Найдите нужную строку и измените поле `icon_name` (и другие поля при
   необходимости).
4. Сохраните строку — изменения появятся на сайте после обновления страницы.

### Через seed-скрипт

Стандартный набор достижений описан в `scripts/appwrite/seed.mjs`.
Для достижений с ID вида `ach_*` скрипт работает как **upsert**: существующие
строки обновляются, новые создаются.

```bash
npm run appwrite:seed
```

> Модули и задания скрипт по-прежнему только создаёт, если их нет, — чтобы не
> перезаписать контент и прогресс.

Legacy-достижения, мигрированные с Supabase, имеют UUID вместо `ach_*` и
seed-скриптом **не обновляются** — их меняйте вручную в Console.

## Формат `icon_name`

Поддерживаются два варианта, оба рендерятся компонентом
`components/achievements/achievement-icon.tsx`:

1. **Эмодзи** (рекомендуется) — например `🎯`, `🏆`, `🔥`.
   Компонент подставляет SVG из Twemoji (CDN jsDelivr), поэтому иконка
   выглядит одинаково на всех платформах. Если CDN недоступен, показывается
   нативный эмодзи.
2. **Имя иконки Lucide** — например `Award`, `Trophy`, `Target`.
   Используется для обратной совместимости с legacy-данными.

Доступные lucide-имена: `Award`, `BookCheck`, `BookOpen`, `Brain`, `Crown`,
`Flame`, `GraduationCap`, `Lightbulb`, `Medal`, `Moon`, `Rocket`, `Sparkles`,
`Star`, `Sunrise`, `Target`, `Trophy`, `Zap`.

Если значение пустое или не распознано, показывается фолбэк `🏆`.

## Схема строки

| Поле | Назначение |
| --- | --- |
| `$id` | ID достижения (стабильный, используется в `user_achievements`) |
| `title` | Название |
| `description` | Описание условия |
| `icon_name` | Эмодзи или имя lucide-иконки |
| `xp_reward` | Награда в XP |
| `condition_type` | Тип условия (`task_count`, `module_count`, `streak_days` и т.д.) |
| `condition_value` | JSON-строка с параметрами условия |
| `is_active` | Показывать ли достижение |
